Cara mengatur kunci AI

  1. Buka editor Apps Script → Project Settings (ikon roda gigi) → Script Properties.
  2. Tambahkan AI_API_KEY, AI_MODEL dan (opsional) AI_BASE_URL.
  3. Kunci tidak pernah disimpan di spreadsheet dan tidak pernah dikirim ke browser.

Cara memasang bot (gratis, Baileys)

  1. Siapkan nomor WhatsApp khusus warung dan perangkat yang menyala terus: HP Android bekas (Termux), PC, atau VPS.
  2. Tekan Buat kode rahasia bot di atas, salin isi .env yang muncul.
  3. Ikuti wa-bot/README.md (folder Source Code): npm install → tempel .env → npm start → masukkan kode pairing di WhatsApp (Perangkat tertaut).
  4. Masukkan nomor bot ke grup pelanggan. Status di atas berubah menjadi Aktif.

Baileys tidak resmi dari WhatsApp. Pakai nomor khusus, jangan kirim pesan massal/promosi — bot hanya membalas & mengabari pemesan.
