Cara mengatur kunci AI

  1. Buka editor Apps Script → Project Settings (ikon roda gigi) → Script Properties.
  2. Tambahkan AI_API_KEY, AI_MODEL dan (opsional) AI_BASE_URL.
  3. Kunci tidak pernah disimpan di spreadsheet dan tidak pernah dikirim ke browser.
