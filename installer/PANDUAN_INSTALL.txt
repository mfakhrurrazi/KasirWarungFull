PANDUAN INSTALL — KasirWarung AI
© 2026 KasirWarung AI · Made by Piyu

Waktu: ± 5 menit, di laptop/PC (Chrome), login dengan akun Google yang akan menjadi PEMILIK aplikasi.
Cara ini TIDAK memerlukan Apps Script API. Semua data (DB_KasirWarung, folder Backup & Ekspor)
otomatis dibuat di folder ini.

File yang dipakai (ada di folder ini):
  • KasirWarung_1_Server.gs     — kode server
  • KasirWarung_2_Tampilan.gs   — semua halaman aplikasi
  • appsscript.json             — pengaturan project


LANGKAH 1 — Buat project Apps Script di folder ini
  1. Buka folder ini di Google Drive → "+ Baru" → "Lainnya" → "Google Apps Script".
     (Sudah punya project dari percobaan sebelumnya? Pakai saja project itu.)
  2. Klik judul project → ganti menjadi:  KasirWarung AI
  3. Klik ikon roda gigi (Project Settings) → centang "Show appsscript.json manifest file in editor".


LANGKAH 2 — Tempel file 1: kode server
  1. Buka "KasirWarung_1_Server.gs" di folder ini → pilih semua (Ctrl+A) → salin (Ctrl+C).
     Jika pratinjau Drive tidak menampilkan seluruh isi: ⋮ → Download → buka dengan Notepad → Ctrl+A, Ctrl+C.
  2. Di editor Apps Script klik "Code.gs" → hapus SEMUA isinya → tempel (Ctrl+V).
  3. Periksa baris paling bawah berakhiran:  const GROCERY_TEMPLATE_CSV = `…`;   → Ctrl+S.


LANGKAH 3 — Tempel file 2: tampilan
  1. Di editor klik "+" (Add a file) → "Script" → beri nama:  Tampilan
  2. Hapus isi default → tempel seluruh isi "KasirWarung_2_Tampilan.gs" → Ctrl+S.
     (Baris terakhir harus:  };  )


LANGKAH 4 — Pengaturan project (appsscript.json)
  1. Klik "appsscript.json" di daftar file editor → hapus SEMUA isinya.
  2. Tempel seluruh isi file "appsscript.json" dari folder ini → Ctrl+S.
  3. Hapus file lain yang tidak dipakai (mis. file installer lama), jika ada.


LANGKAH 5 — Buat database
  1. Di toolbar pilih fungsi "setupDatabase" → klik "Run".
  2. "Authorization required" → Review permissions → pilih akun → "Advanced" →
     "Go to KasirWarung AI (unsafe)" → Allow.  (Peringatan "unsafe" normal untuk script sendiri.)
  3. Execution log menampilkan link DB_KasirWarung. Spreadsheet muncul di folder ini.


LANGKAH 6 — (Opsional) Kunci AI & lisensi
  Project Settings → Script Properties → Add script property:
    AI_API_KEY   = kunci API AI Anda
    AI_MODEL     = nama model
    AI_BASE_URL  = kosongkan untuk default http://43.133.148.28:20128/v1 (disarankan proxy HTTPS)
    LICENSE_KEY  = kunci lisensi (tanpa ini: trial 30 hari)
    SUPPORT_WA   = nomor WhatsApp dukungan, mis. 6281234567890
  Tanpa kunci AI aplikasi tetap berjalan 100% (badge "AI tidak aktif").


LANGKAH 7 — Deploy sebagai Web App
  1. "Deploy" → "New deployment" → ikon roda gigi → "Web app".
  2. Description: KasirWarung AI v1.0.0
  3. Execute as: Me
  4. Who has access: Anyone
  5. Deploy → salin "Web app URL" (berakhiran /exec).


LANGKAH 8 — Mulai jualan
  1. Buka URL /exec di HP → login  admin / admin123
  2. Ikuti Setup Wizard (WAJIB ganti password).
  3. Chrome Android: ⋮ → "Tambahkan ke layar utama".
  4. Pengaturan → Data & Backup → aktifkan "Backup otomatis".


MEMPERBARUI VERSI
  Ganti isi Code.gs dan Tampilan dengan file versi baru → Ctrl+S →
  Deploy → Manage deployments → ✎ Edit → Version: New version → Deploy. URL tetap sama.


JIKA ADA MASALAH
  • "SyntaxError" saat Run → file tidak tersalin utuh. Ulangi salin-tempel (gunakan Download + Notepad).
  • "KW_BUNDLED_HTML is not defined" / halaman kosong → file "Tampilan" belum ditempel (Langkah 3).
  • "Exception: You do not have permission" → jalankan setupDatabase lagi dan klik Allow.
  • "Terlalu banyak percobaan gagal. Coba lagi 15 menit lagi." → tunggu 15 menit, ATAU buka editor
    Apps Script → pilih fungsi "bukaKunciLogin" → Run. Kunci langsung terbuka (hanya bisa oleh pemilik script).
  • "Username atau password salah" padahal sudah admin/admin123 → jalankan setupDatabase sekali lagi
    (membuat akun admin bila belum ada), lalu coba login.
  • Stok/harga diubah langsung di spreadsheet tapi aplikasi belum berubah → tekan tombol muat ulang (⟳)
    di Kasir atau buka menu Produk. Jalankan setupDatabase sekali setelah update agar perubahan manual
    di sheet langsung terbaca otomatis. Saran: ubah stok lewat menu Stok Masuk → Opname agar tercatat.
  • Cara lain (24 file terpisah): folder "Source Code" — buat file dengan nama yang SAMA
    (Script: Code, Data, Setup, Reports, AI, TemplateData — HTML: Index, Styles, Scripts, Page_…).

Panduan lengkap & daftar uji: README.md di folder "Source Code".
